# Prueba Técnica – Desarrollador Full Stack (Sector Financiero)

🔗 **Repositorio:** https://github.com/Ericksanchezr/simulador-formulario-inversion
🔗 **Demo frontend (Vercel):** https://frontend-two-lyart-pm1lgeulzd.vercel.app

Este repositorio contiene la resolución de los dos ejercicios de la prueba técnica:

- [`frontend/`](./frontend) — **Ejercicio 1**: Simulador de Portafolio (React + Vite + Tailwind).
- [`backend/`](./backend) — **Ejercicio 2**: Mini API RESTful de inversiones con autenticación JWT y roles (Node.js + Express).

Cada carpeta tiene su propio `README.md` con instrucciones detalladas de instalación, ejecución y despliegue.

## Resumen rápido

### Frontend (Ejercicio 1)

```bash
cd frontend
npm install
npm run dev
```

Ver [`frontend/README.md`](./frontend/README.md) para detalles y despliegue en Vercel.

### Backend (Ejercicio 2)

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Ver [`backend/README.md`](./backend/README.md) para detalles de los endpoints, roles y cómo probar con Postman/curl.
